RM3100 Scanner - مشروع مسطح (بدون مجلدات) للرفع من الهاتف

1) ارفع كل الملفات (ما عدا android.yml) إلى مستودع GitHub: Add file > Upload files.
2) أنشئ ملف سكربت البناء: Add file > Create new file
   الاسم:   .github/workflows/android.yml
   المحتوى: انسخه من الملف android.yml المرفق.
3) Actions > Build APK > Run workflow ثم نزّل app-debug.apk من Artifacts.
